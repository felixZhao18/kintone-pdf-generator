# 報告書・顛末書アプリ（PDFプレビュー＆印刷プラグイン付き）

kintone上で「報告書」および「顛末書」を作成・管理し、詳細画面からワンクリックでA4レイアウトのPDFをリアルタイム生成・閲覧・印刷できるカスタマイズ一式です。

---

## 💡 概要 / アプリの特徴

- **書類種別による動的レイアウト切替**:
  「報告書」「顛末書」「セキュリティインシデント・情報セキュリティ事象報告」「障害報告書」の種別に応じて、入力フィールドの表示・非表示およびPDFレイアウトが自動で切り替わります。
- **入力行数制限＆リアルタイム警告（Toast）**:
  印刷時のPDFレイアウト崩れを防ぐため、`textarea` の入力行数をリアルタイムで監視。大枠（最大50行）/ 小枠（最大20行）を超過した場合は自動で入力を制御し、警告メッセージを表示します。
- **複数ページ（続紙）＆動的ページ番号対応**:
  2ページ目以降には自動で「続紙ヘッダー（タイトル＋作成者名）」および分割線を描画。フッター中央には `1 / N` 形式のページ番号を正確に印字します。
- **承認ワークフロー連動**:
  プロセス管理（一次承認者 ➔ 二次承認者）およびアクセス権限設定に対応しています。

---

## 📁 含まれるファイル

- `index.js`: メイン制御ソースコード（画面制御、入力制限、PDF生成ロジック）。
- `hide-time-dropdown.css`: カスタムCSSスタイルファイル。
- `報告書.zip`: 本アプリのkintoneアプリテンプレート（書き出し済みZIPファイル）。インポートするだけで即座に環境を構築できます。

## ⚙️ 導入・アップロード手順

1. **JavaScript / CSS カスタマイズ画面を開く**
   - アプリの設定 ＞「JavaScript / CSSでカスタマイズ」を開きます。

2. **PC用のJavaScriptファイルの設定**
   - 以下の順序でファイルを追加・アップロードしてください（※ 順序が異なると動作しない原因となります）。
     1. `https://cdnjs.cloudflare.com/ajax/libs/html2pdf.js/0.9.3/html2pdf.bundle.min.js` （URL指定、またはローカルJS）
     2. `index.js` （アップロード）

3. **PC用のCSSファイルの設定**
   - `hide-time-dropdown.css` をアップロードします。

4. **設定の保存**
   - 画面左上の「保存」をクリックし、アプリの設定画面右上にある **「アプリを更新」** を実行します。
